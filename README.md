# Asteroid Drifter

A small browser arcade game built with Three.js.

## Run locally

```sh
npm install
npm run dev
```

Open the local URL printed by Vite. Use `WASD` or the arrow keys to steer and thrust, `Space` to fire, and `P` or `Escape` to pause. On touchscreens, use the on-screen controls. The **Open in new tab** button launches a separate game tab.

Create a production build with `npm run build`.
